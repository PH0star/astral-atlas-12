# 星穹之書｜ASTRAL ATLAS

離線優先的繁體中文西洋占星 PWA，無須付費 API、占星服務帳號或外部資料庫。目前的私人測試網址需先登入 ChatGPT 才能開啟。部署後首次連網開啟並完成快取，之後可離線計算、查看與儲存。星盤資料儲存在使用者自己的瀏覽器 localStorage；清除瀏覽資料、更換瀏覽器或裝置，以及部分平台由瀏覽器移至獨立安裝的 App，可能無法延用原有資料，請先匯出備份並在新環境匯入。

## 操作

1. 透過 HTTPS 網址開啟，等待離線資源下載完成。
2. 選擇「繪製我的星盤」，輸入出生日期、時間與出生地。可選內建城市或自行輸入緯度、經度、IANA 時區。
3. 檢視太陽、月亮、上升、十二宮、行星與主要相位。需要時手動儲存到本機。
4. 查看流年並選擇年份，下載星盤 PNG、解析 TXT，或從占星紀錄備份／匯入 JSON。
5. 手機安裝：iOS 使用分享選單「加入主畫面」；Android 使用瀏覽器選單「安裝應用程式／加到主畫面」。需在已支援的瀏覽器與 HTTPS 環境中操作；file:// 不支援安裝及 service worker。

## 計算範圍與方法

- 1900–2050 年，緯度 −66° 至 66° 之間（不含端點），經度 −180° 至 180°；避免接近極地時上升點定義與圖示退化造成錯誤。
- 熱帶黃道、地心視黃經；太陽、月亮、水星、金星、火星、木星、土星、天王星、海王星與冥王星採 Astronomy Engine 地心位置並含光行差。上升與天頂用當地視恆星時及黃赤交角公式，並提供等宮制及整宮制。等宮與整宮的第十宮起點不一定是天頂。
- 裝置內建的 IANA 時區資料處理歷史時差與夏令時間；出現重複時間可指定較早或較晚的一次，不存在的時間會拒絕計算。歷史時區的完整性因裝置而異。
- 流年分析對木星、土星、天王星與本命太陽、月亮、上升點，逐日 UTC 00:00 取樣，計算 0°、60°、90°、120°、180° 相位，容許度 2°。區間及最接近日期是近似值，不是精確發生時刻，較短相位可能被漏掉。年度相位期間只反映所選年份範圍。
- 符號性占星詮釋沒有科學驗證，僅供自我探索，非醫療、法律或投資等重大決策的依據。

## 開發／部署

`dist/` 為完整靜態網站，部署時保留整個目錄結構。開發時可用 Node.js 或其他本機伺服器提供該目錄。PWA 與離線功能需 HTTPS 或 localhost。更新快取內容時調整 `dist/sw.js` 的 CACHE 版本。所有圖片及運算程式皆為本地檔案。
